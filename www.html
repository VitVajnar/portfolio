Muzeum Věků Praha

Website · 2026

A website for a fictional Prague museum of world civilisations. Visitors can browse the exhibitions, see what is opening next and book tickets online. The exhibitions load from a CSV file, the gallery is a self-playing carousel, and a countdown runs to the next opening. The booking form is checked in the browser first, then validated and saved by PHP.

Role
Solo — design & development
Tech
HTML · CSS · JS · PHP

Café Kompas

Website · 2025

A responsive website for a small local café. The goal was to make the menu and opening hours effortless to find on a phone. I built a mobile-first layout with CSS Grid and a lightweight PHP contact form. The site loads in under a second on 4G.
