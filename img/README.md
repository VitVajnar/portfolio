# img/

Placeholder SVGs used by index.html. Replace them with your own work
(keep the file names, or update the `src` attributes in index.html).

Tips:
- Web project screenshots: 16:10 (1600×1000 — the browser frame is added by CSS, so use a plain screenshot), export as .webp or .jpg.
- Posters: 3:4; logos and other covers: 16:10; video stills: 16:9.
- For the lightbox you can add a larger version via `data-full="img/poster-large.jpg"`
  on the `<button data-lightbox>` element.
- Update each `alt` text to describe the actual image.
